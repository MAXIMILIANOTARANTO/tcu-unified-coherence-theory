## Filosofía del Archivo

El proyecto TCU opera bajo el principio de **honestidad epistémica radical**.

Esto implica que las ideas que fueron falsadas o superadas **no se borran**. Se archivan aquí con:
- Una descripción clara de qué fue propuesto.
- Por qué fue descartado o falsado.
- Qué aprendizaje produjo.

**El archivo no es un cementerio. Es una bitácora de aprendizaje.**
